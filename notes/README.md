# Notes

Working notes for writing *Chaos from Zero*. None of this is printed.

| File | What it is |
|---|---|
| `01-curriculum.md` | The arc of the book, why the chapters are in this order, and the rules that stop them spending each other's payoffs |
| `02-traps.md` | The catalogue of misreadings, GENERATED from `traps/` by `tools/gen_traps.py`; Appendix B prints the same entries |
| `03-authoring-contract.md` | How a chapter is written: the skeleton, the voice, the numbers, the code, the two editions, and the verification loop |
| `traps/chNN.json` | Each chapter's misreadings, in both languages, numbered from 10N + 1 |

The chapter briefs are not here: they live in `tools/chapters.json`, one per
chapter, and print in each stub until the chapter is written.
